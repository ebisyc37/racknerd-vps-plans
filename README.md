## “不限流量”和“大流量”的实际差距

回到开头那三种形态，具体差别是这样的：

**大带宽真不限流量**。丽萨主机的 4837 不限流量 Lite，198 元/月，2 核 2GB / 40GB NVMe / 200Mbps，流量不封顶，跑多少算多少。Pro 档 498 元/月给到 8 核 8GB / 500Mbps，同样不限。这类方案适合 7×24 挂着跑采集、推流、多账号矩阵，用量完全不可预测的场景。

**窄带宽真不限流量**。丽萨的 CN2 GIA 系列走另一条路，1Mbps 档 30 元/月、2Mbps 档 65 元/月、5Mbps 档 299 元/月，往上到 20Mbps 要 1999 元/月。带宽本身就是天花板，1Mbps 的理论峰值是 125KB/s，满载一天跑 10GB 出头。挂个轻量脚本、单人代理够用，多几个人共享立刻卡住。

**大带宽配大额度**。RackNerd 这五档属于这一类。端口给到 1Gbps 不打折，但每月流量有明确上限，3TB 到 20TB 不等。好处是价格压得很低，$21.99 一年的钱在丽萨那边只够买 1Mbps 不限流量档一个月；代价是用量得自己盯着，超了要处理。

三种形态的价格差得离谱，本质是商家在赌你的实际用量。真不限流量的方案，商家必须按最坏情况预留带宽，成本自然高；给固定额度的方案，商家可以超卖，价格就能压下来。

## 1Gbps 端口在国内能跑多快

这是前排文章最常回避的问题。答案是：大概率跑不满，而且和你买哪家关系不大。

第三方对六六云美国 VPS 的测评可以拿来当参照。那款机器标称 1000Mbps 端口，50 元/月配 1TB 流量，测评者从国内本地下载实测 10.8MB/s，折算下来接近百兆水平。测评里的解释是跨太平洋的国际出口有物理限制，本地带宽跑不满标称值是常态。同一份测评还测了延迟：全国三网平均 212ms，电信 185ms、联通 256ms、移动 205ms，100 个海内外节点零丢包，三网回程全部从美国机房直连回国。

这个结论对 RackNerd 同样成立。1Gbps 端口的意义在于三个地方：机房本地和同机房其他机器之间的传输、多线程并发时的总量、以及晚高峰别人挤的时候你还有余量。指望单线程从国内拉文件跑出 100MB/s，任何美国机房都给不了。

如果你的用途是从国内实时操作这台机器（远程桌面、SSH 敲命令、开代理），延迟比带宽重要得多，RackNerd 这类国际线路的机器不是最优解，中转或者选带大陆优化线路的机房更实际。如果机器主要在那边自己跑任务，你只是偶尔连上去看结果，1Gbps 端口加 3TB 流量这个组合的性价比就很难被比下去。
